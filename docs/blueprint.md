# **App Name**: Tractări Sibiu Pro

## Core Features:

- Service Information Display: Clearly present information on all available services: car towing, car transport, roadside assistance, and 24/7 emergency roadside service, using `next/image` for relevant visuals.
- Emergency Call-to-Action: Implement a prominent 'SUNĂ ACUM 📞' button that is sticky at the bottom on mobile devices, enabling direct phone calls (0700 000 000).
- Responsive & Mobile-First Design: Ensure a fully responsive, mobile-first layout that adapts seamlessly to all screen sizes using Tailwind CSS.
- Hero Section Content: Display a compelling hero section with the main headline: 'Tractări Auto Sibiu — Rapid, 24/7, Profesional' and integrate trust signals.
- Trust Signals Integration: Prominently feature trust signals such as '24/7 disponibilitate', 'timp de răspuns 30 min', and 'zona Sibiu și județ'.
- SEO & Performance Optimization: Configure JSON-LD for LocalBusiness schema, Open Graph meta tags, and utilize `next/image` for optimized image delivery to ensure high page speed and discoverability.

## Style Guidelines:

- Primary interactive color: Vibrant orange (#FF6B00) for important actions and highlights. The app employs a dark color scheme.
- Background color: Deep charcoal black (#0A0A0A) for a modern, professional, and dark aesthetic, providing excellent contrast for text.
- Text color: Pure white (#FFFFFF) for maximum legibility against the dark background.
- Accent color: Vivid red (#FF3344) to provide strong visual emphasis for critical alerts or secondary interactive elements, chosen to be analogous to the primary color yet distinct.
- Body and headline font: 'Inter', a neutral and highly legible grotesque-style sans-serif, ensuring clear communication and a modern, professional feel across the site.
- Use clear, concise vector icons depicting towing services, emergency, 24/7 availability, and location, designed in a monochrome or dual-tone style to complement the dark theme and vibrant orange accents.
- A mobile-first, grid-based responsive layout prioritizing ease of access to emergency contact and service information, featuring a sticky call-to-action bar at the bottom on smaller screens.
- Subtle, fast-loading micro-animations for interactive elements like buttons and navigation items to provide immediate feedback without distracting from the emergency-focused content.
